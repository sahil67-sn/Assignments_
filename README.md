# Sahil Mohammad — HTML & CSS Assignments Showcase

🔗 **Live Website:** [View Assignments](https://sahil67-sn.github.io/Assignments_/)

This website showcases **11 HTML and CSS assignments** completed as part of the **BCA 1st Year — Web Programming** coursework. It brings the assignments together on one page, where each assignment has a short description and a link to view it.

## Assignments

| # | Assignment | Description |
|---|---|---|
| 01 | Background Image | Demonstrates a full-page background image using CSS size, position, and repeat settings. |
| 02 | News Page | A news-style page with headlines, images, and article sections. |
| 03 | Flex Box | Demonstrates CSS Flexbox for arranging and aligning content. |
| 04 | Dynamic Gallery | A responsive image gallery that adapts to different screen sizes. |
| 05 | Profile UI/UX | A profile page focused on layout, spacing, and user experience. |
| 06 | Nav Bar | A navigation bar with menu links, hover effects, and responsive styling. |
| 07 | Iframe | Demonstrates embedding another webpage or content using the HTML iframe element. |
| 08 | Table | An HTML table with rows, columns, headers, borders, and spacing. |
| 09 | Box Model | Demonstrates the CSS box model: content, padding, border, and margin. |
| 10 | Login/Signup | Styled login and signup forms with input fields and buttons. |
| 11 | Animation | CSS animations and keyframes that add movement and transitions to elements. |

## Technologies Used
